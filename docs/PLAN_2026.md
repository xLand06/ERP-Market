#### 2.1 Toma de inventario físico (Stocktaking)

**Modelo de datos:**
```prisma
model StockCount {
  id          String   @id @default(cuid())
  status      StockCountStatus @default(DRAFT) // DRAFT, IN_PROGRESS, COMPLETED, CANCELLED
  notes       String?
  createdAt   DateTime @default(now())
  completedAt DateTime?
  
  branchId String
  branch   Branch @relation(...)
  
  createdById String
  createdBy   User   @relation(...)
  
  items StockCountItem[]
}

model StockCountItem {
  id             String  @id @default(cuid())
  expectedStock  Decimal // stock lógico actual
  countedStock   Decimal // stock físico ingresado
  difference     Decimal // countedStock - expectedStock (calculado)
  
  productId String
  product   Product @relation(...)
  
  stockCountId String
  stockCount   StockCount @relation(...)
}
```

**Flujo:**
1. OWNER crea un conteo → selecciona productos (o "todos").
2. Sistema precarga `expectedStock` del `BranchInventory`.
3. Usuario ingresa `countedStock` para cada producto (puede ser con lector de código).
4. Al completar: sistema calcula diferencias y opcionalmente ajusta `BranchInventory.stock`.
5. Reporte de diferencias: producto, stock lógico, stock físico, diferencia, valor de la diferencia (costo).

#### 2.2 Lotes y Vencimientos

**Modelo de datos:**
```prisma
model ProductBatch {
  id         String  @id @default(cuid())
  batchCode  String  // código de lote del proveedor
  expiryDate DateTime
  quantity   Decimal @default(0)
  costPrice  Decimal? // precio de costo de este lote
  
  productId String
  product   Product @relation(...)
  
  branchId String
  branch   Branch @relation(...)
  
  @@unique([batchCode, productId, branchId])
}
```

**Integración:**
- **Compra (PurchaseOrder → RECEIVED):** al recibir mercancía, pedir lote y vencimiento por producto
- **Venta (POS):** al vender, descontar del lote con fecha de vencimiento más próxima (FIFO)
- **Dashboard de alertas:** productos próximos a vencer (30 días, 7 días, vencidos)
- **Merma automática:** al vencer un lote, sugerir registrarlo como merma
